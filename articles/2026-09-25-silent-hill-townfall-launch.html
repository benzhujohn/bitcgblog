《Silent Hill: Townfall》发售后：81 分、零差评却口碑割裂，第一人称赌注到底成了没

本站在 9/8 写过《Townfall》的发售前前瞻（苏格兰孤岛 St. Amelia、便携 CRT 电视 CRTV、5 结局、系列首次第一人称）。9/24 正式上线，评测解禁——Metacritic 81、OpenCritic 82，零负评，但口碑明显割裂。一句话先放上：它是复兴三部曲里最弱的一部，可"氛围"依然能把你按在椅子上；问题出在它用 stealth 当骨架，而 stealth 没撑住。

一、细节拆解：分数、平台，和"被一致点赞 / 一致骂"的两极

评分落点：Metacritic 81（PS5），OpenCritic 82，约 86% 推荐（部分 outlet 称 92%）。它低于《SH2 重制》（86/87）与《SH f》（86）——是复兴三部曲里最弱的一作。Metro 给 7/10；VGC 的标题最传神："Outstanding horror marred by infuriating stealth（出色的恐怖，毁于令人抓狂的潜行）"。平台与价格：PS5 + PC（Steam / Epic），$49.99，PS5 半年主机独占；Annapurna Interactive 联合发行。主角 Simon Ordell，由 Jovan Adepo 配音；5 个结局，其中 2 个是 NG+ 隐藏结局。

被一致点赞的，是"氛围"。多家媒体称这是系列最佳之一：音效设计、St. Amelia 那座雾锁的苏格兰渔村、手持 CRT 电视 CRTV（把老寂静岭的"收音机警告"升级成可以主动调频的解谜工具），以及"把羞耻处理得比近十年任何一部寂静岭都好"的故事——这条评价是多家共识。它被一致骂的，是 stealth：敌人 AI 与躲藏机制对不齐，你常搞不清自己哪个动作惊动了怪；后段 stealth 重复；checkpoint 过于 brutal；逻辑谜题有时发傻；bug 频繁（非致命，但出戏）。

PC 端还有个翻车点：UE5 微卡顿（microstutter / traversal stutter）。Steam 当前"多半好评"，但置顶最有帮助的评测是一篇退款——"氛围确实好，但我为了卡顿退了"。Steam Deck 低画质下 30–40fps 能玩，但仍有明显掉帧。

二、深度分析：第一人称赌注，成了多少

先说它赢的部分。第一人称确实更吓人——你离怪物更近、感官更压迫，但也更累、更"费力"，同时丢了系列招牌的第三人称距离感。对"寂静岭是一种心理现象"的重构是成立的，但"用 stealth 来承载心理恐怖"是一步险棋：当 stealth 系统本身不可靠，恐惧就退化成了 frustration（挫败）。这正是 Townfall 的核心矛盾——它想用机制制造不安，机制自己却先崩了。

放进复兴三部曲的坐标：后两部（SH2 重制、SH f）守住了"演出 + 战斗 / 和风怪谈"，Townfall 用"苏格兰冷雾写实 + 独立厂实验分支"来补位。它不是来超越的，是来扩圈的。制作人 Okamoto 曾放话"可能是复兴作的 masterpiece"——分数只部分应验。把 IP 交给 Screen Burn（前 No Code，《Stray》《Observation》班底）主导，证明 Konami 愿意为"作者性"做外部实验；代价是体量与会打磨不如内部大作。

谁该买、谁可以等，其实很清楚：冲氛围 / 叙事 / 怪谈 → 可冲；冲 stealth 手感与稳定帧 → 等两三个补丁，或先走 PS+ 后入。对恐怖新手，建议先拿 SH2 重制打底，再来碰这部更实验、更不友好的 Townsfall。

三、8bitACG 编辑部解读

我们的评分：7.8。比 9/8 前瞻的 8.2 下调，扣在 stealth 与优化；但"氛围"单拆，我们给到 9.0。

我们的观察："零负评"在动作 / 恐怖游戏里极罕见，但 Townfall 的零负评更像"没人否认可怕"，而不是"大家都说它好"。这是两件事，别被聚合页的漂亮数字骗了。

我们的观点：复兴三部曲"用不同视角覆盖不同受众"的策略是对的——重制、和风、实验三线并行。但 Townfall 证明"第一人称 + stealth"是其中最难收口的组合；下一部该回到更可靠的恐怖语法，而不是继续在系统层冒险。

我们的案例 / 对比：把它和《Signalis》《Alan Wake 2》对照——前者用有限资源做"可信的恐怖系统"，后者用光影做"可靠的惊吓节奏"；Townfall 卡在中间：想做系统，系统却拉胯。它不缺野心，缺的是把野心焊牢的那层打磨。

我们的实验（分玩家行动清单）：我们在前瞻里提过"全潜行 vs 正面刚"双打法；发售后补一条 PC 端实测——先关光追、降画质保 60fps，因为对 stealth 来说容错比帧数更重要。PS5 主机党可冲（手柄自适应扳机加分）；PC 玩家等 Day-one patch 后的优化补丁；恐怖新手先玩 SH2 重制打底。

四、总结

Townfall 不是复兴的失败，是一次"敢但不完美"的实验。它把寂静岭搬进了苏格兰的冷雾，用一台便携电视重构了恐惧的界面，却在 stealth 与优化上掉了链子。如果你买的是"2026 最被低估的氛围怪谈"，它值；如果你买的是"又一款 86 分复兴作"，它会让你失望。给它一两个补丁，它会更接近它本该有的样子。
